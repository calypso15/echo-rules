# Careers

The book's [careers](05-step-2-career.md) work fine — divers need the same professions the packs are built around. Changes:

- **Mindhacker** is removed. Psychosurgery does not exist.
- **Genehacker** is kept (genetic medicine and smart-animal work exist via Watcher-derived biotech), but reads as a cutting-edge biotech specialist, not an uplift designer.
- **Face** may also be called **Face/Dealer** to match the gear packs.
- **Operator** is added — the single most common profession in the diving economy.
