# Echo Protocol

A homebrew campaign setting for **Eclipse Phase 2e**. Earth, 2047 — eleven years after humanity launched nuclear strikes against the Watchers' twelve ECHO outposts, divers descend into the two intact alien structures for governments, hypercorps, and the highest bidder.
